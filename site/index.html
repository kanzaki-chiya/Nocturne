06:30

还有这些

内置 79 个服务商预设，也可接入任意 OpenAI 兼容或 Anthropic 兼容接口。

回退和分叉
从任一条消息回退或分叉，对话与文件一并还原。
排队和插话
运行中继续发消息，不必先中断当前回合。
目标模式
/goal 交办多步目标，模型自行推进到验证通过。
多代理攻坚
/fugue 拆给多个后台子代理，各自在独立工作树修改后并回。
组曲
同一长期目标下的指挥对话、工作线程和共享说明集中管理。
子代理
查找、调研或跨文件修改交给独立子会话，只带回结果。
记忆
跨会话保存偏好、纠正过的做法和项目约束。
技能
按需加载的提示词与支持文件，用到时才读取正文。
上下文和用量
接近上限时自动两级压缩，跨会话统计 Token 与费用。
MCP
接入外部工具服务器，也可作为 MCP 服务器供其他工具调用。
插件
支持自有插件，并可只读接入本机已装的 Codex 与 Claude Code 插件。
Hook
在固定的生命周期事件点运行外部命令。
外部 Agent
通过 ACP 接入 Codex、omp 等命令行工具。
电脑操控
Windows 桌面端可在授权的软件里点击、输入和操作窗口。
文档处理
内置 Word、电子表格、演示文档与 PDF 处理。
