# ADR-0123 桌面会话中的手动压缩反馈

状态：已接受。适用于桌面端已有的 `/compact` 入口。

1. 用户提交 `/compact` 后，命令立即从输入框移走，会话末尾就地显示「正在压缩上下文 · 0 秒」，以秒显示已用时间。样式沿用会话中的思考状态。用户可以继续编辑草稿，提交后的异步回调不能清除新草稿。
2. 成功时同一位置显示「上下文已压缩 · 用时 12 秒」（数字取实际耗时），与已有摘要压缩回执合为一条。用户停止时显示「压缩已停止」，失败时显示具体错误。结束后停止计时。原有回执携带的摘要和交互需要保留。
3. 状态和耗时归属于发起操作的会话。切走再回来能看到正确进度或结果。在未取得起始时间的旧会话历史中，沿用已有回执。普通消息、其他斜杠命令和自动压缩的既有语义保持兼容。
