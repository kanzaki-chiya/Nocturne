# ADR-0114：项目页面库

- 状态：已接受（2026-11-24）
- 修订：[ADR-0109](ADR-0109-page-versions.md)「不做的事」中「跨会话页面库」一项
- 相关：[ADR-0109](ADR-0109-page-versions.md)（页面版本）、[ADR-0111](ADR-0111-page-storage-and-model.md)（页面数据）、[ADR-0098](ADR-0098-memory.md)（项目键）、[ADR-0113](ADR-0113-page-comments.md)（页面评论）
- 效果图：Phase 12 设计稿第 ① 节（页面库布局，不含类型筛选行与评论圆点）

## 背景

面板页面（`/cadenza` 或用户明确要求时生成）是用户反复查看、反复让模型修改的东西，但现在只能在生成它的那个会话里找到：换个会话就看不到，也没法接着改；做过的页面多了，要翻会话列表才能找回上周那张图。目标形态按项目列出全部页面，任何会话都能打开、接着改。

页面仍放在 Nocturne 数据目录，不往仓库里写文件。

## 决定

### 1. 范围

- 只收**面板页面**（`SessionPage.display === "panel"`）。内嵌页面是回复里的随文小图，不进页面库。
- 本期只做桌面端。手机网页、安卓、TUI 后续再做。

### 2. 归属与数据来源

- **项目**：用 [ADR-0098](ADR-0098-memory.md) 的项目键（主仓库根目录，工作树映射回主仓库）。会话按 `workspaceRoot` 归入项目；默认工作区（`<NOCTURNE_HOME>/workspace`）的会话归入「对话」。项目键计算抽成共用函数，记忆与页面库共用，不复制实现。
- **数据来源**：页面库完全由各会话的 `SessionView.pages` 派生，不新增真相源。版本 HTML 仍是各会话的附件，页面数据仍按 [ADR-0111](ADR-0111-page-storage-and-model.md) 存在各会话目录。回退、删除会话、分叉的效果自然反映在页面库里。
- **收录哪些会话**：项目下的顶层会话，含已归档会话；不含子会话、合奏成员和组曲线程。
- **缓存**：为避免每次打开页面库都完整重放所有会话日志，可以按会话加一份可重建的旁路摘要（以日志修改时间判断是否过期），内容只是该会话面板页面的 `{ page, title, version, updatedAt, origin }`。缓存损坏或缺失时重新派生，不当真相源。

### 3. 同一页面的多个副本

分叉会把页面复制到新会话；第 5 节的跨会话接着改也会产生新副本。页面库要把它们当成同一个页面：

- **来源（`origin`）**：每个面板页面有一个来源 `{ sessionId, page }`，即这条血缘里最早创建它的会话与页面 id。
  - 在本会话新建的页面：来源是自己。
  - 分叉得来的页面（分叉点之前就存在）：来源沿用源会话里该页面的来源。
  - 跨会话接着改产生的页面：来源沿用被接着改的那个页面的来源。
- **页面库一行一个来源**：显示这条血缘里最近更新的副本（最新版本的时间最晚者）；版本号、标题、会话名取该副本。

### 4. 桌面页面库

- 侧栏导航在「组曲」下方加「页面」（页面图标），点击后主区显示页面库，样式与现有「定时任务」「组曲」主区一致。
- 顶部：标题「页面」，右侧为项目选择（显示项目文件夹名或「对话」，下拉列出有面板页面的项目，默认取当前会话所在项目）与搜索框（按页面标题、会话标题匹配）。
- 列表分「置顶」「最近」两组，按最近更新时间倒序。每行：页面图标（置顶行用图钉图标）、页面标题、会话标题、`v<n>`、更新时间（今天显示 `HH:mm`，否则 `MM-DD`）。
- 点击一行：切到该副本所在会话，打开它的面板页面标签并显示最新版。会话已归档时照样打开。
- 右键菜单：「置顶」「取消置顶」。置顶按来源记在桌面端偏好里，按设备保存。
- 本期不显示类型筛选（只有一种类型）；类型、评论圆点在后续期加入。
- 不写任何说明文字、占位提示或空状态说明；列表为空时只显示标题栏。

### 5. 跨会话接着改

- **新工具 `list_pages`**（只读、免确认、仅主会话，与 `render_html` 同样的可用范围）：列出当前会话所在项目的面板页面，每项给 `ref`（最近副本的 `<sessionId>/<page>`）、标题、最新版本号、更新时间、最新版本 HTML 的绝对路径。按最近更新倒序。
- **`render_html` 的 `page` 接受 `<sessionId>/<page>`**：指向同项目另一会话的面板页面时，在当前会话新建一个页面（本会话新编号 `page-<n>`），`edits` 以被指页面最新版为底稿，版本号接着被指页面最新版加一，显示方式为面板，来源按第 3 节沿用；被指页面的数据文件（[ADR-0111](ADR-0111-page-storage-and-model.md)）复制一份到当前会话，之后各写各的。指向其他项目或不存在的页面时返回 `invalid_input` 并列出可用的 `ref`。
- **读取放行**：同项目其他会话中面板页面的版本 HTML 文件，`read` 免确认。规则在权限层生成（与「本会话落盘目录可读」同一处），工具与 UI 不自行判定。
- 工具说明写明：用户要接着改别的会话里的页面时先用 `list_pages` 找到 `ref`，再用 `render_html` 传 `page: "<ref>"`。

### 6. 兼容

- 附件 `inline` 新增可选 `from?: { session: string; page: string }`（跨会话接着改时记录被指页面），沿用非 `.strict()` 写法，不提升 `formatVersion`。来源由派生计算，不另存。
- 旧会话无需迁移：旧面板页面的来源就是自己。

## 不做的事

- 不把页面复制进仓库或单独的项目目录。
- 不做重命名、删除单个页面（删页面跟着删会话或回退）。
- 不做类型筛选、评论圆点、手机端页面库（后续期）。
