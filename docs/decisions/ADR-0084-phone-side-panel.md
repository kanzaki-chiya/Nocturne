# ADR-0084：手机侧边栏——右抽屉总览、只读子视图与远程只读方法

- 状态：已接受
- 日期：2026-11-10
- 修订：[ADR-0060](ADR-0060-desktop-side-panel.md) 第 8 节「不做手机端的面板」：改为提供只读的会话侧边栏，桌面侧面板的终端、内置浏览器与文件编辑仍不上手机；[ADR-0052](ADR-0052-remote-web-client.md) 2026-10-15 的能力上限：新增只读的子代理观察与会话内受限读文件
- 用户行为见 [apps/desktop.md 第 8 节](../apps/desktop.md#8-手机网页) 与 [site-docs/remote.md](../../site-docs/remote.md)

## 背景

手机会话页的顶栏现在要放返回、标题、上下文用量圆环、「…」会话菜单与后台任务入口，窄屏上放不下，且上下文、子代理、变更、文件要么各有一套入口，要么没有入口。原有的两个入口也不够用：

- 输入框上方只列尚未送达的后台子代理，看不到同步子代理，也不能查看子代理过程；
- 顶栏的「后台任务」弹层只能看后台命令，打开后盖住对话，切去看别的观察对象要先关掉再找入口，不能就地切换。

远程侧的能力同样不完整：`subagent.list` / `subagent.subscribe` / `subagent.unsubscribe` 不在远程白名单，手机拿不到同步子会话的只读事件；`runtime.readFile` 是为桌面读取本机任意文件设计的，可读范围远大于会话工作区，不能直接开放给远程。

维护者已定：用一个右侧抽屉收拢会话内的只读观察入口，顶栏只保留会话菜单与侧边栏按钮；终端暂不开放。

## 决定

### 1. 顶栏与抽屉

- 会话页顶栏右侧只保留两个入口：「…」会话菜单与侧边栏按钮。会话菜单内容不变，仍是重命名、压缩上下文、MCP 状态、输入历史与只读的 Shell 信息。上下文用量圆环从顶栏移除，上下文百分比、累计 tokens 与构成改在侧边栏总览里显示。
- 侧边栏是右侧抽屉，宽 88%，从顶栏下沿开始，不盖住顶栏；顶栏以下的其余界面由遮罩压暗。
- 关闭方式：点遮罩、再点一次侧边栏按钮、按安卓返回键。抽屉的总览与子视图都占会话页的 history 层：从子视图返回先回到总览，再返回才关闭抽屉；安卓返回键与返回手势走同一条 `history.back()` 路径。

### 2. 总览

总览自上而下：

- 上下文百分比、累计 tokens 与构成，复用桌面的上下文面板；
- 运行中的子代理：同步与后台内置子代理一起列出，按子代理目录的运行状态筛选，不显示「后台」标记，也没有行内取消。外部 ACP 没有 Nocturne 子会话，不进入侧边栏；
- 后台命令：运行中与刚结束的（结束五分钟内）都列出，没有行内停止；
- 底部三个入口：「变更」「文件」「终端」。

没有子代理或后台命令条目时，对应分组不显示。

#### 修订（2026-11-13）：合奏分组

- 当前会话有进行中的合奏（[ADR-0089](ADR-0089-ensemble.md)）时，在「上下文」之后、「子代理」之前显示「合奏」分组；合奏结束后整组隐藏。原对话流内的入口行与「成员数 · 帖子数」计数移除，改由侧边栏和桌面概览统一承接，避免把无单位计数与多处跳转混在消息流里。
- 分组头部显示状态圆点与任务标题，点击压入全屏合奏页；其下每名未移除成员一行，左侧为与留言板一致的作者小头像（有待确认权限时带警告色描边），第一行为成员名与模型/档位（独立工作树另标「独立工作树」），第二行为最近活动摘要（待确认时用警告色），点击直接压入该成员的会话页。由侧边栏进入全屏合奏页或成员会话页后，安卓返回键与返回手势回到侧边栏总览，与子代理详情返回一致。

### 3. 子视图

子视图都是只读的，不提供对父会话的输入、权限或提问应答、重发、分叉、中断：

- **子代理**：复用桌面已有的只读观察链路（`SubagentWatcher` 与共享 `Conversation` 的只读渲染），思考、工具与输出按主对话样式显示；不 resume 子会话、不取锁。后台子代理可在详情里取消（调用既有的 `subagent.cancel`），同步子代理没有取消。
- **变更**：按轮读取 `session.turnChanges` 与 `session.turnChangeDiff`，显示只读 diff；不提供撤销，撤销仍在本轮改动卡片或桌面端。
- **文件**：列表来自 `session.fileIndex`，文本文件用桌面 `code-viewer` 的只读渲染打开并自动换行；读取走新增的 `session.readFile`，二进制文件不显示内容。
- **后台命令**：只读输出，沿用桌面输出观察的首读尾部、按偏移追加与上滚保持位置；运行中可在详情里停止（`shell.kill`），总览没有停止按钮。
- **终端**：虚线边框、淡色的静态行，`aria-disabled`，不响应点击，不写说明。本轮不开放远程终端。

### 4. 删除旧入口

输入框上方的后台子代理条与顶栏的旧「后台任务」弹层入口一并删除，观察入口只在侧边栏。后台子代理结果仍以待发条目的形式撤回，未送达的结果不因为删除旧入口而丢失。

### 5. 远程只读方法

子代理方法只新增以下三个只读方法，不新增其他 `subagent.*`；另有 `session.readFile` 见下：

- `subagent.list`、`subagent.subscribe`、`subagent.unsubscribe` 只允许本连接已打开的父会话及其直接子会话；父会话没有在该连接打开时拒绝。`unsubscribe` 只撤本连接自己的订阅，断线、关闭父会话或父会话空闲关闭时，按现有子代理观察的清理规则撤订，不延长子会话的锁或运行寿命。
- `subagent.cancel` 不因本 ADR 改变：它仍是会话内操作、已允许远程（[ADR-0073](ADR-0073-background-subagents.md)），只在后台子代理详情里出现。

新增 `session.readFile` 作为会话内的受限只读文本读取：

- 它与 [ADR-0060](ADR-0060-desktop-side-panel.md) 2026-10-18 撤下的同名未发布方法不是同一契约：本次是会话工作区、文件索引与远程上限共同限定的只读文本读取，不复用 `runtime.readFile` 的本机任意文件口径；
- 按会话工作区解析路径，拒绝 `..` 越出工作区；按真实路径（解析符号链接后）复核仍在工作区内，拒绝符号链接逃逸；
- 只允许读取 `session.fileIndex` 当前列出的文件；
- 只返回文本，二进制文件不返回内容；
- 超过远程读取上限时返回明确的 `file_too_large` 错误，错误里带文件字节数；不截断内容，客户端只显示文件大小。

`runtime.readFile` 保持只在本机，不加入远程白名单；桌面文件面板继续用它。远程不新增直接执行命令的接口，终端入口仍未开放；`shell.tasks` / `shell.output` / `shell.kill` 保持 ADR-0083 的只读观察与停止范围。

### 6. 契约位置

远程方法的精确参数、返回结构、错误码与白名单清单以 [rpc.md](../protocols/rpc.md) 第 4.1、7 节为唯一主表，随实现同步补齐；本 ADR 只确定范围与边界，不预先固定字段形状。

## 后果

- 手机有了统一的只读观察入口，顶栏不再挤入更多图标；子代理、变更、文件与后台命令可以在同一个抽屉里就地切换，不必反复开关弹层。
- 观察与桌面共用同一套视图、订阅与清理规则，减少两端行为分叉；手机仍不能推进子会话、替它确认或操作终端，只有后台子代理能在详情里取消。
- 取消后台子代理与停止后台命令只放在详情里，减少总览上的误触；同步子代理没有取消，不会出现点了没反应的按钮。
- 远程读文件的范围收窄到会话工作区与文件索引，仍可能读到工作区里的敏感文本；风险由配对、设备吊销与后台白名单承担，不把 `runtime.readFile` 的任意文件能力带到手机。
- 新增远程方法增加维护面；实现落地时 `rpc.md` 第 4.1、7 节要同步补齐，旧入口删除后截图也要更新。
- 终端以不可用的静态行保留在总览里，用户能看到入口位置但暂时用不了；本轮不为它写说明。

## 备选方案

- **继续在顶栏加图标或把观察入口塞进「…」会话菜单**：顶栏放不下，会话菜单是会话操作，混入观察入口会让两类操作互相牵制。否决。
- **沿用底部弹层或新页面分别查看子代理、变更、文件**：每项各弹一次，不能就地切换，返回后对话位置与上下文断开。否决，改用一个抽屉内的同级子视图。
- **直接复用桌面侧面板**：桌面面板带终端、内置浏览器与文件编辑，远程没有对应宿主，也会把用户引到不可用的功能上。否决，只做只读子集。
- **开放 `runtime.readFile`**：它按本机任意文件设计，不适合远程；`session.readFile` 以会话工作区和文件索引收窄范围。否决。
- **超限时截断文件**：静默截断会让用户以为看到了全文；改为明确的 `file_too_large` 与文件大小。否决。
- **在总览行内放取消与停止**：触控下误触代价高，且同步子代理不可取消；统一放到详情。否决。
