# ADR-0125 用 Open Artifact 替换华彩

状态：已接受。实施分为 r1126f、r1126g 两批，依次验收。

## 产品方向

移除用户可见的「华彩」执行方式。`render_html` 只用于在聊天回复中展示图表，例如一张就地说明趋势的折线图。新建页面、仪表盘、交互小工具以及需要单独打开和编辑的作品统一走 Open Artifact。用户在 Nocturne 会话里提出要求，在右侧面板打开编辑器，编辑、导出和把评论送回会话都在 Nocturne 内完成。同步收窄 `render_html` 的工具声明、参数和模型使用说明，移除新建或更新面板作品的调用入口；历史工具调用仍能回放。

## 第一批：清退华彩，保留内嵌图表与历史

- 从桌面、手机网页、安卓、TUI、逐行 CLI 的命令菜单、帮助和新请求协议移除华彩。区分新提交与历史解码：`workMode: "cadenza"` 的旧事件仍可恢复和回放。隔离面板创建和更新入口时同时核对省略 `display` 且传旧 `page` 的路径。
- `render_html` 的生成指引只覆盖当前回复内嵌图表，包括图例、悬停等读图交互；沿用图表所需的沙箱和配色。历史面板、版本、讨论串、页面数据和下载按原格式读取。查看自己的旧作品无需安装或启动新运行时。第一批交付时不宣称 Open Artifact 已可用。

## 第二批：Open Artifact 接入 Nocturne

- 用户入口为 **Open Artifact**（`/artifact`），自然语言创建作品也走相同路径。采用上游原生类型及编辑器，包含 Design（多方案、可点击的 HTML 画板）和 Page（自由 HTML 页面）。桌面从会话卡片打开独立的受限视图；项目页面库可找到旧页面和新作品。新作品以稳定的 `open-artifact://` 标识与项目、会话关联，重启后重新解析本地地址。
- 桌面随包交付匹配的固定版 CLI 运行时与 harness-kit，按需启动或连接本地 daemon。宿主用真实会话及工作区绑定工具调用、文件写入与作品。所有者发送的评论送回归属会话，忙时排队，重连补投须防重复；其他来源保留为通知。保持现有宿主权限边界，编辑器只加载 daemon 明确声明的来源，不向作品暴露 Tauri 权限。普通退出只断开本客户端。随包分发上游 LICENSE、NOTICE 与适用第三方声明。
- 本机终端给出可用的作品入口。移动端首版展示作品信息并提示在桌面打开；不向远程设备发送宿主的回环链接。上游托管、公开分享服务和旧作品批量转换均不在这两批范围内。

## 发布前验收

在同一会话分别要求「画一张本周用量折线图」和「做一个可编辑的用量仪表盘」：前者以内嵌图表显示，后者通过 Open Artifact 打开。核对模型工具清单已移除 `render_html` 的面板生成入口。在全新 Windows 安装环境创建一个设计画布，从聊天打开右侧编辑器，手改一处并从具体画板发送评论。切到另一会话时，原会话仍收到正确反馈；模型更新后手改内容保留。重启后从项目页面库重新打开同一作品，再实际导出文件。另用升级前的会话验证旧命令记录、旧页面版本和评论可读。核验包体积、macOS 打包结果以及最终选定的移动端行为。

第一批在独立分支接受主审；第二批工作树从第一批验收的完整提交创建。两批可分别测试和回退；用户安装的数据不作为迁移、改写或清理对象。
