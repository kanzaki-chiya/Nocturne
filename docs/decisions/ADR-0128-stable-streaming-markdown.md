# ADR-0128 会话流式输出的阅读稳定性

状态：已接受。适用于桌面和手机共享的会话正文。

1. 普通文字随生成可读。后续内容追加时，保留已定型段落的文字节点、阅读位置和浏览器选区。正在成形的末段可以变化。用户已向上阅读时保持阅读锚点，用户跟随底部时沿用自动跟读。
2. 表格在 Markdown 分隔行足以确定列结构后排版；围栏代码保持可读，沿用闭合后启动高亮的行为。数学排版归 ADR-0126，公式渲染器存在时只在定界符闭合后排版。未完成或无法判定的内容在结束或中断时按已有 Markdown 语义呈现。
3. 同一条回复从实时状态转为历史条目时，在视口内保留已读正文和选区。最终排版与直接打开相同历史消息一致，复制原文、引用、文件链接、思考、工具和审批保留原有行为。Core 仍按原协议发流式事件。
4. 用相同分片输入做前后对照，在短会话与已进入虚拟列表的长会话里，实际观察「选中第一段 → 后续表格或代码流入 → 回复完成」全程。功能完成以可复核的浏览器行为为准。
