# ADR-0045：统一全屏页骨架

- 状态：已接受
- 日期：2026-10-04

## 背景

TUI 现在有三张常用的全屏页：服务商页（`/provider`）、模型选择页（`/model`）和设置页（`/settings`）。它们是在不同的 ADR 里分别做出来的，放在一起看很割裂：

| | 服务商页 | 模型选择页 | 设置页 |
|---|---|---|---|
| 外框与底色 | 无框，终端底色 | 无框，终端底色 | 圆角框，整屏 `overlayBg` |
| 页头 | 像素字标加标题与说明 | 无页头，只有「全部模型 • 1/340」 | `/settings 设置` 加一行说明 |
| 主体 | 单列 | 左栏导航加右栏列表 | 单列，分段控件整行铺开 |
| 选中标记 | `▶` 加整行高亮 | `>`、`>*d` 混用 | `>` 加整行高亮 |
| 过滤 | 顶部「过滤:」 | 打字即搜，不显示查询 | 无 |
| 底部 | 提示行，`•` 分隔 | 详情区加提示行，空格分隔 | 提示行，`·` 分隔，下方取消/保存按钮 |
| 保存 | 每个操作各自生效 | 选中即生效 | 草稿，底部统一保存 |

问题有两类。一是**层级混淆**：设置页整屏套了对话框的框和底色，用户分不清自己在页面上还是在弹窗里。二是**细节各自为政**：页头、选中标记、提示行格式、过滤位置、保存方式都不一样，每加一张页面就多一种写法。

[ADR-0030](ADR-0030-dialog-settings-pages.md) 统一了对话框，但没有规定"页面"本身该长什么样。本 ADR 补上这一层。

## 决定

### 1. 两层：页面与对话框

- **页面**（服务商页、模型选择页、设置页，以及之后的回退页、主题页）整帧替换主界面，**不画外框，使用终端底色**。
- **对话框**沿用 ADR-0030 的 `DialogFrame`：圆角框加局部 `overlayBg`，居中覆盖在页面上，下层页面冻结输入。模型编辑、压缩阈值、安全审查、服务商操作都属于这一层。
- 设置页去掉现在的整屏外框与底色。

### 2. 统一页头

- 第一行是**面包屑标题**，主色加粗，层级用 ` › ` 连接：`设置`、`服务商`、`服务商 › opencode-go › 模型`、`模型`。标题右侧可以放一个灰色计数（如 `1/340`、`5 已配置`）。
- 第二行是一句灰色说明，没有就省略。设置页沿用「默认值对新会话生效；当前会话用 Alt+M 切换权限、Shift+Tab 切换思考档位」。
- 有过滤查询时，说明行下方显示 `过滤: <查询>`，没有查询时不占行。
- 像素字标只出现在空会话欢迎区（[ADR-0039](ADR-0039-welcome-provider-dialogs.md) 第 1 节）和首次启动的配置向导里，从 `/provider` 进入服务商页时不再显示。

### 3. 主体布局：双栏

三张页面统一用**双栏**：左栏是分组或范围导航，右栏是条目列表，中间一条 `border` 色竖线，竖线在底部细线处画成 `┴`。用户在效果图里比较过三种方案后选定这一种，另外两种见「备选方案」。

```
设置
默认值对新会话生效；当前会话用 Alt+M 切换权限、Shift+Tab 切换思考档位

  会话默认        │  会话默认
  界面            │▌ 默认权限预设    ‹ smart ›                         设置
  执行            │  安全审查        Jev · opencode-zen · jev-1.13-free  设置
  模型角色        │  默认模型与档位  deepseek-v4.1-flash · high  在 /model 设置
                  │
                  │  界面
                  │  主题            ‹ 深色 ›                          设置
                  │  …
──────────────────┴─────────────────────────────────────────────────────────
默认权限预设  guarded 范围内直接执行；规则拦下的操作先交审查器判断，拿不准再问你
保存在 settings.json · 当前会话用 Alt+M 临时切换

↑↓ 移动  ←→ 修改  Enter 打开  Tab 切换栏  Esc 返回
```

- **左栏**固定 18 列（含竖线）。条目过长时末尾截断加 `…`。
- **左栏的作用**：
  - 设置页和服务商页的左栏是**跳转**：在左栏移动时，右栏滚到对应分组的第一项。
  - 模型选择页的左栏是**范围筛选**，沿用现有行为：「最近使用」「全部模型」、细线、已配置服务商（`●` 名称加模型数）、细线、未配置服务商（`○`，灰色）。
- **右栏**按分组列出全部条目，每组以主色加粗的组名开头，组与组之间空一行。
- **切换栏**：所有页面都用 `Tab`/`Shift+Tab`。服务商页和模型选择页的右栏没有可改的值，`←`/`→` 也可以切换栏；设置页的 `←`/`→` 用来修改值。
- **各页右栏的列**：
  - 设置页：名称、值、来源（右对齐）。
  - 服务商页：状态点（有效 `success`、已失效 `warning`、未配置 `○` 灰色）、名称、状态、认证方式，模型数右对齐；当前会话使用的服务商在模型数左侧加主色标签 `当前`。分为「已配置」「可添加」两组。
  - 模型选择页：模型名、能力标记（`R`/`I`）、上下文（右对齐），之后是 `当前`（主色）、`默认`（`accentAlt`）标签。「最近使用」组按新到旧排序，其后是「其余模型」组。
- **通用规则**：
  - 名称列按页内最长名称的显示宽度对齐；附注列（来源、能力、状态）用 `muted`。
  - 只读行的值用 `muted`，并在附注里说明去哪里改（如「在 /model 设置」）。
  - 分组名不加编号。

### 4. 统一选中与焦点

- 选中行整行铺 `selectionBg`，行首画主色的 `▌`，文字用 `selected`。这个样式替换现在的 `▶`、`>`、`>*d`。
- 模型选择页里「当前会话」「默认模型」的标记改成附注列里的文字标签（`当前`、`默认`），不再挤在行首。
- 双栏时只有获得焦点的那一栏画选中样式，另一栏的已选项只用主色文字标出。

### 5. 统一底部

底部自下而上固定两部分：

- **提示行**：`键 动作` 成对出现，键用 `secondary`，动作用 `muted`，对与对之间空两格，不用 `•` 或 `·`。例如 `↑↓ 移动  ←→ 修改  Enter 打开  Esc 返回`。
- **说明区**：提示行上方，用一条 `border` 色细线隔开，显示当前选中项的说明或详情，最多两行。设置页显示该项是做什么的；模型选择页显示上下文、最大输出、能力与当前/默认标记（即现在的详情区）；服务商页显示认证方式、账号与模型数。保存失败等错误也显示在这里，用 `error` 色。

### 6. 统一过滤

所有列表页直接打字即过滤，Backspace 删除，Esc 先清空查询、再按一次返回。查询显示位置见第 2 节。设置页按名称和说明文字过滤。

### 7. 设置页逐项保存

设置页去掉底部的取消/保存按钮，改为**逐项保存**：

- **单值项**（默认权限预设、主题）：`←`/`→` 切换后立即写入 `settings.json`，值列显示为 `‹ smart ›` 形态，不再整行铺开所有选项。主题切换同时即时生效。
- **复合项**（安全审查、压缩阈值、Shell、模型角色）：Enter 打开对话框或选择页。对话框里的「保存」就是落盘，取消不写任何东西。
- 写入失败时值回到原来的样子，说明区显示错误。
- `Esc` 直接返回，不再弹放弃确认。

这一条修订 [ADR-0034](ADR-0034-settings-layer.md) 第 5 节的「保存方式」。当时不选立即保存，理由是多字段设置需要一起保存和校验；按本节，多字段设置都在各自的对话框里一起保存，单值项没有这个顾虑。ADR-0034 的其余规则（来源标记、覆盖提示、默认模型与档位只在 `/model` 成对修改）不变。

### 8. 共享骨架组件

`apps/tui/src/components/page/` 新增 `PageShell`，负责页头、过滤行、主体视口、说明区与提示行的布局和退化；三张页面只提供各自的行数据和按键处理。窄屏退化：

- 终端宽度小于 72 列时左栏折叠成主体上方的一行当前分组名（`‹ 会话默认 ›`），`Tab` 切换分组。

- 高度不足时依次去掉说明行、说明区，最后只保留标题行、列表和提示行。
- ASCII 模式下 `▌` 换成 `>`，细线用 `-`；NO_COLOR 保留 `▌`/`>` 标记和文字标签。

鼠标规则沿用 ADR-0030 与 [ADR-0039](ADR-0039-welcome-provider-dialogs.md)：单击选中，再单击已选中行执行 Enter 的动作。

### 9. 实现分两轮

1. 抽出 `PageShell`，按双栏改设置页，并完成第 7 节的逐项保存。
2. 服务商页、模型选择页套用 `PageShell`；回退页与主题页只套用页头和底部。

## 后果

- 三张页面共享一套骨架，以后加页面只写行数据和按键，界面自然一致。
- 设置页的「整页取消」没有了，误改单值项需要手动改回；复合项仍在对话框里有取消。
- `docs/apps/tui.md` 第 7、8、11 节的页面描述要按本 ADR 重写；ADR-0034 追加修订。
- 现有页面测试的帧快照几乎都要更新。

## 备选方案

- **只统一提示行和选中标记，不动布局**：改动最小，但层级混淆（设置页整屏套框）和三种布局并存的问题都还在。
- **设置页保留草稿模式，其他页面立即生效**：保留整页取消，但同一套骨架里两种保存方式并存，正是要解决的割裂之一。
- **分节单栏**：不要左栏，分组名后面拖一条细线作为分节标题，模型选择页的服务商改为页头下的筛选标签。最安静，但服务商多了标签要横向滚动，条目多时只能靠过滤。
- **顶部标签**：页头下方一排主色底块标签，每个标签一页。`←`/`→` 已用于改值，切标签只能用 Tab；设置页每个标签只有一到三项，显得零碎。
