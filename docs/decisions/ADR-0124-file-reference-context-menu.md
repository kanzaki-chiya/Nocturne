# ADR-0124 Windows 桌面会话文件引用右键菜单

状态：已接受。适用范围是 Windows 桌面端会话正文中的文件引用。

1. 普通工作区文件的一级菜单依次为「打开」「打开方式 ›」「在资源管理器中显示」、分隔线、「复制相对路径」「复制绝对路径」。相对路径相对该引用所属工作区。没有工作区相对路径时只提供绝对路径复制。
2. 「打开」与该文件的左键共用设置里的默认打开方式，保留面板、系统默认、编辑器及适用的行号定位。右键点「打开方式」临时选择应用，不改 Nocturne 偏好。工作区内 HTML 的「打开」仍遵循现有预览设置，一级菜单采用相同顺序。
3. 二级菜单最多显示三个 Windows 推荐应用，沿用现有系统应用列表的去重、默认优先与其余项的返回顺序；不足三个按实际数。最后一项为「更多打开方式…」，调用 Windows 原生“打开方式”对话框，用所选应用打开当前文件；取消即返回。普通文件没有推荐项时仍可打开原生选择器。
4. 「在资源管理器中显示」在父目录中选中该项。工作区目录的「打开」进入目录，目录省略「打开方式」。沿用现有工作区外打开限制、缺失或网络路径处理以及 ADR-0046、ADR-0102 的可执行文件保护。受保护类型沿用可用的安全编辑器入口，系统选择器遵守同一保护。
