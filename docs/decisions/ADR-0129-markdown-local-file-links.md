# ADR-0129 会话 Markdown 链接引用本地文件

状态：已接受。补充 ADR-0046、ADR-0060 和 ADR-0124。

用户收到 `[验收报告](<Z:/nocturne-mockups/impl/r1126i/report.md>)` 时，只看到没有交互的「验收报告」。`marked` 已保留标题与目标；桌面会话将未通过外链白名单的目标统一显示为普通文字。

在已落盘的会话消息中，把明确的本地文件目标交给已有的文件引用解析器。标题保留原有 Markdown 样式，悬停显示实际路径，左键、键盘和右键复用行内代码文件引用行为。相对路径以所属会话工作区为准，带行号的目标沿用现有定位能力。工作区外文件、目录和受保护文件类型沿用既有边界。

网页链接仍遵守既有外链规则。UNC、协议相对网址、设备路径、`file:` 和其他未放行 URI 不访问文件系统。锚点不作文件查找。缺失文件、无法解析和不支持本地打开的客户端保留可读标题。流式期间避免针对半截路径发起解析；正式消息或历史重开后使用同一逻辑。
