# ADR-0092：桌面端界面改版（工作台方向）

- 状态：已接受
- 日期：2026-11-15
- 修订：[DESIGN.md](../../DESIGN.md)、[apps/desktop.md](../apps/desktop.md)

## 背景

桌面端现有界面「廉价感」的来源有三：

1. **层次混乱**：标题栏仅覆盖主区右侧，左栏独立延顶并自带品牌头，同时主区与内部块使用多层圆角与卡片嵌套，平面秩序不统一。
2. **字小且灰**：正文与次要信息在对比度、字号层级和混排规则上区分不够明确，大量中文标签偏灰或与机器值混用字体。
3. **侧栏噪音多**：会话列表每行同时叠放状态圆点、相对时间和右侧标签，配合偏紫调的选中态，视觉负担较重。

## 决定

采用 B「工作台（Workbench）」方向重构桌面端界面基础与关键区域：

- **单层平铺与外框**：标题栏（`40px`）、侧栏（`248px`）与主区处于同一平面，只靠 `1px` `--a-border` 细线分隔；主区去掉圆角、阴影与外边距，底色 `--a-bg`。标题栏左侧放置 `16px` `MoonMark` 标志与「Nocturne」，去掉侧栏重复品牌头；「设置」入口置于侧栏底部；侧栏会话行去掉状态圆点与相对时间；新会话页垂直居中排列 `36px` `MoonMark`、标题（`18px` 间距）与输入框。
- **中性色与字阶**：保持强调色、语义色与高亮色不变，仅将表面色、边框和选中态调整为中性灰；新增 `--a-btn` / `--a-on-btn` 供实心发送按钮使用。随包引入 `@fontsource-variable/inter` 与 `@fontsource-variable/jetbrains-mono`（仅 `latin` 子集，中文由系统字体回退），「设置 › 外观」自选字体仍插在栈首。等宽字体只用于机器读的值（路径、命令、分支、diff、模型 ID），中文标签、分组标题与统计数字使用 `--sans` 并配合 `tabular-nums`。`--fs-5` 由 `22px` 调为 `20px`，圆角梯度收敛为 `--radius-1`（`4px`）、`--radius-2`（`6px`）、`--radius-3`（`8px`），新增 `--radius-composer`（`10px`）专用于输入框外框。
- **去掉底部状态栏**：原状态栏各项按以下去处迁移或移除：

| 原项 | 去处 |
|---|---|
| 运行状态点与文字、第 N 轮 | 删掉；运行中由输入框的中断按钮表达 |
| 上下文进度条与百分比、累计 tokens、缓存命中 | 输入框底栏右侧、模型名左边的 `18px` 上下文圆环，点击在上方弹出上下文面板（底部显示「累计 N tokens」与「缓存 N%」） |
| 生成速度 | 删掉；只在「用量」页查看 |
| 分支 | 对话标题行，标题右边，复用 `BranchMenu`，等宽字、分支图标 |
| MCP 未连接标记 | 输入框「+」右上角 `6px` 红点，点开见「+」菜单内的 MCP 子菜单 |
| 远程在线标记 | 删掉；状态只在「设置 › 远程」里查看 |
| 电脑操控中的软件名与「停止」 | 对话标题行右侧、任务和面板按钮左边，只在前台送达期间出现；全局快捷键 `Ctrl+Alt+Esc` 不变 |

- **输入框底栏与「+」菜单**：附件单独作为回形针图标按钮放在底栏；「+」菜单放置五种执行方式（追问需求、目标、计划、多代理攻坚、合奏）、技能子菜单与 MCP 子菜单；原「引用文件…」菜单项移除，输入 `@` 引用文件保持不变。

## 后果

为控制变更范围并便于逐步验收，改版分三轮落地：

1. **第 1 轮（本轮基础）**：更新中性色/选中色/字体/圆角/侧栏宽度 token、随包引入 Inter 与 JetBrains Mono 变量字体（latin 子集）、改造标题栏、侧栏、主区平铺与新会话页标志标题，并同步修复现有页面因新 token 引起的视觉问题。
2. **第 2 轮（状态栏与输入框）**：移除底部状态栏并完成上表各项迁移，重构输入框底栏、上下文圆环、「+」菜单及执行方式标签。
3. **第 3 轮（对话区与设置页）**：按工作台规格收敛对话消息气泡、工具行、diff 卡片与设置页排版细节。

- **正面影响**：消除多层嵌套卡片的割裂感，西文与等宽代码字形在不同平台上保持一致，侧栏与主区信息密度更聚焦。
- **约束**：新增 CSS 仍需通过 stylelint 与 `check-css-vars.mjs` 校验，界面继续严守不写描述性占位或解释文字的原则；手机网页共享 token 但保持自身布局与触控尺寸不变。

## 备选方案

## 备选方案

- **A「纸面」**：采用灰底板叠放白卡的方式建立层次，虽然块边界清晰，但在设置页和分栏面板下容易继续产生卡片套卡片的视觉噪音，与去掉装饰性边框的桌面工作台目标相悖，未采用。
- **C「夜曲」**：采用深夜色底板配合衬线/宋体标题强化品牌氛围，但编程与终端混排场景下衬线大标题与高密度等宽信息容易产生风格割裂，不利于长期高频阅读与紧凑排版，未采用。

## 修订记录

- **2026-11-15（第 2 轮已落地）**：移除 `StatusBar` 与 `--h-statusbar` 等状态栏 token；新增 `ContextUsage`（18px SVG 圆环 + 面板底部累计 tokens 与缓存占比）与 `ConversationHeader`（标题行 Git 分支与电脑操控「停止」）；重构 `Composer` 底栏、「＋」菜单（执行方式单选 +「技能 ›」「MCP ›」级联子菜单 + MCP 异常红点）、回形针「添加文件」与执行方式标签，新增 `--radius-send`（7px）；同步更新侧栏运行中会话 12px 环形转圈与桌面斜杠命令提示。
- **2026-11-15（第 2 轮托盘补充）**：新会话页工作区与 Git 分支（非仓库及普通对话隐藏分支 chip）从底栏挪入 `.cbox` 下方紧贴的 `.tray` 托盘，菜单向下弹出，工作区最宽 `320px`、分支最宽 `240px` 省略；会话页不变、无托盘。
