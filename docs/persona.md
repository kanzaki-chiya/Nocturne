# 角色设定：Noctelia（夜璃）

本文记录 Nocturne 看板娘的已定设定，作为后续人设功能、文案与视觉设计的参考。角色功能尚未开发，本文不对应任何现有实现。

## 定位

Noctelia 是 Nocturne 的看板娘 / 虚拟形象。**Nocturne 是产品名，Noctelia 是角色名**，两者不得混用：产品、命令、系统提示词中的身份仍是 Nocturne；只有指代角色时才使用下面的名字。

## 命名

| 语言 | 正式名 | 日常称呼 | 说明 |
|---|---|---|---|
| 英文 | Noctelia | Elia | Elia 是官方昵称；不使用 "Noct"，避免与产品名 Nocturne 混淆 |
| 中文 | 夜璃 | 夜璃 | — |
| 日文 | 夜璃（より / Yori） | より | 首次出现时写作「夜璃（より）」标注读音，之后可直接用「より」 |

## 人设

- **性格**：清冷、冷静可靠，话不多但很靠谱的技术型角色，陪开发者深夜写代码。
- **视觉意象**：夜晚、深蓝、月光、玻璃 / 琉璃质感。

## 后续开发备注

- 目前仓库没有 i18n。以后加入时，按语言使用对应名字：en → Noctelia / Elia，zh → 夜璃，ja → 夜璃（より）/ より。
- 若要让 Agent 以角色人设对话，需要改动系统提示词组装（见 [architecture/context.md](architecture/context.md)），并同步更新该文档。
