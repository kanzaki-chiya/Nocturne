# 手机远程

手机远程功能允许你通过手机浏览器查看和操控电脑上正在运行的 Nocturne 桌面端会话，包括发消息、插话与排队、切换模型与权限预设，以及审批桌面端等待确认的工具调用。

安卓手机可以改用 App：在 [GitHub Releases](https://github.com/kanzaki-chiya/Nocturne/releases) 下载 `nocturne-{{version}}.apk`，配对时扫描电脑上的二维码或粘贴配对链接，再确认这台手机的名称。设置 › 关于可检查更新，新版本会在首页提示，下载由系统下载管理器写入下载目录（不可用时回退系统浏览器打开 Release APK），完成后点系统通知安装。

## 登记中继服务器

手机与电脑之间通过中继服务器（Relay）转发加密报文。首次使用需先登记中继：

1. 向中继服务管理员获取一次性邀请码（以 `nocturne-invite:` 开头）。
2. 在桌面端打开「设置」→「远程」，在「让手机连到这台电脑」分组的「中继邀请」输入框粘贴邀请码，点击「登记」。
3. 登记成功后，「中继」分组会显示中继域名与连接状态（「已连接」、「连接中」或断开提示），并开启「允许远程访问」开关。临时不需要远程连接时，可随时关闭「允许远程访问」开关。

## 局域网直连（安卓 App）

在桌面端「设置」→「远程」的「中继」分组打开「局域网直连」开关（默认关闭）后，当安卓手机与电脑处于同一局域网时，安卓 App 会自动与电脑直接建立端到端加密连接，不在同一局域网时继续经中继转发；扫码配对与设备管理仍通过中继完成。该开关仅对安卓 App 生效，手机浏览器网页版仍走中继。在 Windows 上首次打开该开关时，系统会弹出防火墙放行提示，允许在专用网络/局域网通信即可。

## 配对新手机

1. 确保「中继」状态为「已连接」且已开启「允许远程访问」，点击右上角「配对新手机」。
2. 桌面端弹出「配对新手机」对话框，显示「手机配对二维码」和临时「配对链接」（可点击「复制」）。
3. 用手机相机扫描二维码（或在手机浏览器打开配对链接），在手机网页上确认配对。配对完成后对话框显示「已配对」并自动关闭。

手机端网页支持创建和切换会话、发送消息、排队与插话、从历史消息「编辑并重发」或「分叉」，以及审批工具权限请求；但服务商密钥、MCP 服务器、项目信任与授权管理等敏感设置仅限在电脑桌面端操作。点击会话内已加载的图片或输入框待发缩略图可打开全屏查看器，支持双指缩放、双触放大与同组左右滑动切换，按返回键先关闭查看器（超过远程上限的图片只显示提示；安卓 App 内隐藏复制按钮，下载图片或对话文件附件会调起系统保存界面选择位置）。模型生成的回复内嵌页面同样在对话内直接显示，右上角常显全屏按钮，全屏内可下载 `.html` 文件或按返回键关闭。

后台命令的工具状态、可折叠结果卡片与[待发结果撤回](queue.md#管理待发队列)和桌面端一致，展开原工具行可实时查看输出，结果卡片可查看送达的输出尾部。

## 会话侧边栏

会话页顶栏右侧只有「…」会话菜单与侧边栏按钮。侧边栏是从右侧打开的抽屉，宽度约为屏幕的 88%，从顶栏下方开始；点遮罩、再点侧边栏按钮或按安卓返回键关闭。子页面返回时先回到总览，再返回关闭侧边栏。

总览显示当前会话的上下文占用、已用 tokens 与构成，正在运行的子代理（同步与后台），以及运行中和刚结束的后台命令，底部是「变更」「文件」「终端」三个入口；没有条目的分组不显示。

- **子代理**：点开查看它的思考、工具与输出，显示方式与主对话一致；只读，不能给它发消息或替它确认。后台子代理可以在详情里取消，同步子代理没有取消。
- **变更**：按轮查看只读的改动与 diff，不能在这里撤销。
- **文件**：按文件索引列出文件，文本文件以只读代码视图打开并自动换行；二进制文件不显示内容，超过读取上限时只显示文件大小。
- **后台命令**：点开查看只读的实时输出，运行中可以在详情里停止；总览里没有停止按钮。
- **终端**：入口暂不可用。

顶栏的会话菜单仍提供重命名、压缩上下文、MCP 状态、输入历史与只读的 Shell 信息。输入框上方不再显示后台子代理列表。

## 设备管理与断开

手机断开后，正在运行的对话、后台子代理和后台命令会继续执行，结果照常送达；空闲且未暂停的会话会自动接着处理结果。后台工作与接续对话全部结束后，没有客户端打开的会话才释放资源。期间重连可继续查看同一会话。退出电脑端后台仍会中断并丢弃未交付的后台工作。

- **状态栏快捷查看**：当有已配对手机在线时，桌面端会话底部状态栏会显示「手机在线」按钮；点击可展开「在线手机」浮层，直接对单台设备点击「断开」或点击「打开远程设置」。
- **管理已配对设备**：在「设置」→「远程」的「已配对设备」列表中，可查看每台手机的在线状态、最近在线时间与推送订阅状态（显示「已订阅推送」或「无推送订阅」）：
  - 点击「断开」：立即断开该手机当前的在线连接；
  - 点击「移除」并在确认框中确认：解除该手机的配对关系，移除后需重新扫码配对。
- **退出登记**：在「中继」分组点击「退出登记」并在确认框中确认，会注销当前电脑在中继上的登记并移除全部已配对手机。

## 端到端加密与信任边界

- **端到端加密**：手机与电脑桌面端在配对时通过公钥握手建立端到端加密通道，业务载荷全部加密传输。中继服务器只负责转发密文与投递 Web Push 唤醒通知，看不到你的对话内容、代码、文件路径或命令输出。
- **信任边界**：手机端运行的网页前端由中继服务器托管提供，因此你仍需信任中继管理员不会篡改手机网页代码（被篡改的前端可在手机浏览器解密后读取内容）。建议仅使用自建或由可信团队维护的中继服务。
