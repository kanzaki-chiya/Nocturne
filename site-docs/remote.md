# 手机远程

手机远程功能允许你通过手机浏览器查看和操控电脑上正在运行的 Nocturne 桌面端会话，包括发消息、插话与排队、切换模型与权限预设，以及审批桌面端等待确认的工具调用。

安卓手机可以改用 App：在 [GitHub Releases](https://github.com/kanzaki-chiya/Nocturne/releases) 下载 `nocturne-{{version}}.apk`，配对时扫描电脑上的二维码或粘贴配对链接，再确认这台手机的名称。设置 › 关于可检查更新，新版本会在首页提示，下载由系统浏览器打开维护者的 Release APK。

## 登记中继服务器

手机与电脑之间通过中继服务器（Relay）转发加密报文。首次使用需先登记中继：

1. 向中继服务管理员获取一次性邀请码（以 `nocturne-invite:` 开头）。
2. 在桌面端打开「设置」→「远程」，在「让手机连到这台电脑」分组的「中继邀请」输入框粘贴邀请码，点击「登记」。
3. 登记成功后，「中继」分组会显示中继域名与连接状态（「已连接」、「连接中」或断开提示），并开启「允许远程访问」开关。临时不需要远程连接时，可随时关闭「允许远程访问」开关。

## 配对新手机

1. 确保「中继」状态为「已连接」且已开启「允许远程访问」，点击右上角「配对新手机」。
2. 桌面端弹出「配对新手机」对话框，显示「手机配对二维码」和临时「配对链接」（可点击「复制」）。
3. 用手机相机扫描二维码（或在手机浏览器打开配对链接），在手机网页上确认配对。配对完成后对话框显示「已配对」并自动关闭。

手机端网页支持创建和切换会话、发送消息、排队与插话、从历史消息「编辑并重发」或「分叉」，以及审批工具权限请求；但服务商密钥、MCP 服务器、项目信任与授权管理等敏感设置仅限在电脑桌面端操作。

会话顶栏的终端图标打开「后台任务」概览，列出运行中的命令和结束未满五分钟的任务。点击任务进入只读输出页，实时查看并选择复制输出；运行时可在页头点击「停止」。长命令单行省略，输出自动换行。

后台命令的工具状态、可折叠结果卡片与[待发结果撤回](queue.md#管理待发队列)和桌面端一致，展开原工具行可实时查看输出，结果卡片可查看送达的输出尾部。

## 设备管理与断开

- **状态栏快捷查看**：当有已配对手机在线时，桌面端会话底部状态栏会显示「手机在线」按钮；点击可展开「在线手机」浮层，直接对单台设备点击「断开」或点击「打开远程设置」。
- **管理已配对设备**：在「设置」→「远程」的「已配对设备」列表中，可查看每台手机的在线状态、最近在线时间与推送订阅状态（显示「已订阅推送」或「无推送订阅」）：
  - 点击「断开」：立即断开该手机当前的在线连接；
  - 点击「移除」并在确认框中确认：解除该手机的配对关系，移除后需重新扫码配对。
- **退出登记**：在「中继」分组点击「退出登记」并在确认框中确认，会注销当前电脑在中继上的登记并移除全部已配对手机。

## 端到端加密与信任边界

- **端到端加密**：手机与电脑桌面端在配对时通过公钥握手建立端到端加密通道，业务载荷全部加密传输。中继服务器只负责转发密文与投递 Web Push 唤醒通知，看不到你的对话内容、代码、文件路径或命令输出。
- **信任边界**：手机端运行的网页前端由中继服务器托管提供，因此你仍需信任中继管理员不会篡改手机网页代码（被篡改的前端可在手机浏览器解密后读取内容）。建议仅使用自建或由可信团队维护的中继服务。
