# 手机远程

## 配对连接步骤

通过手机远程功能，你可以在手机浏览器上查看桌面端正在运行的会话、发送消息、切换模型以及审批权限请求。

1. 在桌面端打开「设置 → 远程连接」。
2. 在「连接」分组中开启「启用手机远程」（默认「中继地址」为 `wss://relay.nocturne.YetAnother.App`，也可改为自建中继地址后点击「应用」）。
3. 连接状态变为「已连接」后，在「配对新设备」分组点击「生成配对码」。
4. 桌面端会展示配对二维码、配对链接和 6 位数字配对码（有效期 60 秒）。
5. 用手机相机扫描二维码（或点击「复制链接」在手机浏览器打开并输入配对码），验证通过后即进入手机端会话界面。

## 端到端加密

手机与桌面端之间的所有业务数据均采用**端到端加密（E2EE）**：

- 配对阶段双方通过 PAKE 协议与 X25519 密钥协商派生独立的会话密钥；
- 会话消息、代码片段、工具输出和权限审批全部在本地完成 AEAD 加密后再发出；
- 中继服务器（Relay）只负责按房间转发密文帧，不持有密钥，无法解密任何对话内容或凭据。

## 设备管理与撤销

已配对的手机设备记录保存在本机 `~/.nocturne/remote.json`（最多同时配对 5 台设备）。

在桌面端「设置 → 远程连接」的「已配对设备」列表中，可以查看每台设备的名称、首次配对时间、最近连接时间和当前「在线」状态。点击任意设备右侧的「撤销」（或点击列表右上角的「全部撤销」），即可立即吊销该设备的访问权限并断开连接。

## 自建中继服务

Nocturne 的中继服务（`@nocturne/relay`）是轻量无状态的转发服务，同时托管手机端静态网页。你可以使用仓库 `apps/relay/deploy/` 目录下的 `docker-compose.yml` 与 Caddy 配置在自己的服务器上部署，然后将桌面端的「中继地址」改为你的 `wss://` 域名并点击「应用」。
