# 第一个会话

## 打开项目与新建会话

- **桌面端**：点击左侧边栏底部的「打开项目」选择本地代码仓库目录，再点击项目旁的 `+`（或按 `Ctrl+N` / `⌘N`）新建会话；如果不需要绑定代码目录，也可直接点击左侧边栏顶部的「新对话」开始无工作区对话。
- **终端版**：在项目根目录下运行 `nocturne`，即以当前目录作为工作区启动会话。

## 提问与附加上下文

### 发送与换行

- 在输入框按 `Enter` 发送消息，按 `Shift+Enter` 换行（桌面端可在「设置 → 通用 → 发送消息」中改为 `Ctrl+Enter / ⌘Enter 发送`；TUI 中还可用 `Ctrl+J` 或行尾 `\` 加 `Enter` 换行）。
- 模型运行中如果需要补充说明或安排后续任务，参见 [排队和插话](queue.md)。

### 引用工作区文件

1. 在输入框中输入 `@`（或点击桌面端输入框左下角的「引用文件（@）」按钮），会弹出当前工作区的文件与目录补全列表。
2. 输入路径或文件名关键词筛选，按 `Enter` 或 `Tab` 选中，即可插入 `@相对路径`。
3. 发送后 Nocturne 会自动读取被引用文件的内容（或列出目录项）附在消息中交给模型；桌面端也支持将文件从系统文件管理器拖入输入框，或按 `Ctrl+P` / `⌘P` 快速打开项目文件。

### 附加图片

在桌面端会话中，当所选模型支持图片输入时，可在输入框中直接按 `Ctrl+V` / `⌘V` 粘贴剪贴板图片，点击输入框左下角的「添加图片」按钮选择图片，或直接将图片拖入输入框（支持 PNG、JPEG、GIF、WebP，单张不超过 10 MB）。

## 查看改动与撤销

### 查看本轮改动

当模型在一轮对话中通过文件编辑工具新建、修改或删除了工作区文件，该轮回复下方会显示变更汇总卡片（如 `3 个文件变更 +42 -10`）：

- 点击卡片上的「查看详情」，会在 [右侧面板](panels.md) 的「变更」标签页中打开本轮全部改动。
- 点击卡片展开文件列表后，点击任意文件名可在面板中定位到该文件的 Diff。

### 停止与撤销

- **停止**：模型正在输出或执行工具时，点击输入框右下角的「停止」按钮或按 `Esc` 立即中止当前轮次。
- **撤销**：点击本轮变更卡片上的「全部撤销」（或单个文件旁的「撤销」），可将工作区文件一键还原到本轮修改前的状态。如果需要连同对话历史一起回退到更早的消息节点，参见 [回退和分叉](rewind.md)。
