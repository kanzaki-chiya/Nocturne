# 第一个会话

配好服务商后，就可以打开代码仓库开始提问和修改代码。

## 打开项目或开始对话

- **桌面端**：点击左栏「项目」旁的 `+`（`打开项目…`）选择本地仓库文件夹；也可以在新建会话页输入框左下方点击目录按钮，在菜单中选择「普通对话」、已有项目或「打开其他文件夹…」。之后把鼠标悬停在左栏项目名上点击 `+`，或点击左栏顶部的「＋ 新会话」，即可新建会话。
- **终端**：进入代码仓库目录后直接运行 `nctrn`。

「普通对话」不绑定具体项目仓库，其默认工作目录可在「设置」→「常规」的「普通对话」分组中查看或点击「更改…」调整。

在桌面端，点击左栏「新会话」下方的「搜索」或按 `Ctrl+K`（macOS 为 `Cmd+K`）可打开跨会话搜索弹窗：未输入关键词时展示「最近使用」；输入关键词后可在「全部」、「会话」、「项目」、「设计」和「定时任务」五栏中搜索会话标题、用户消息、助手正文与工具输出，以及项目名称/路径和定时任务名称/提示词。用 `↑` / `↓` 选择结果（光标在输入框首尾时按 `←` / `→` 切换分栏），按 `Enter` 即可打开对应会话并跳到命中位置、展开侧栏对应项目或打开对应定时任务。

项目与定时任务随输入立即筛选；会话结果扫描后分批追加，首批到达前保留上次的会话结果。继续输入会自动忽略旧查询结果，追加不会改变当前选中项。

## 提问、引用文件与发图

在「输入消息」框内输入问题，按 `Enter` 发送，`Shift+Enter` 换行。模型运行期间按 `Esc` 或点击输入框右侧的 `■` 可中断当前回合。

- **引用仓库文件**：输入 `@`（或点击输入框左下角 `＋` →「引用文件…」）打开「文件引用补全」，搜索并选中仓库内的文件，发送时会自动附带文件内容。
- **添加图片或文件**：点击输入框左下角 `＋` →「添加文件…」，或直接把文件、截图粘贴/拖入输入框（支持 `image/png`、`image/jpeg`、`image/gif`、`image/webp` 等；粘贴满 32 KB 的长文本也会自动转为附件）。若当前模型不支持看图且已在「设置」→「模型」配置了「视觉模型」，会先由视觉模型生成图片描述再交给当前模型。

## 查看思考、代码定位与改动

- **思考过程**：支持推理的模型会显示「思考中」，点击标题可展开查看完整推理过程，或点击「收起思考」折叠。
- **跳转代码位置**：回答中形如 `src/index.ts:42` 的行内代码如果对应真实存在的文件，左键点击会按「默认打开方式」直接打开并跳到对应行（默认为「Nocturne 面板」，可在「设置」→「常规」改为「系统默认程序」、「VS Code」或「Cursor」）；右键点击可选择「打开」、「资源管理器」、「复制绝对路径」或「复制相对路径」。
- **本轮改动卡片**：每当模型通过文件编辑工具修改了文件，该轮回复底部会汇总一张改动卡片，列出本轮已编辑的文件数与增删行数。点击文件名可在卡片内展开 Diff，点击「查看变更」会在右侧面板的「变更」标签页中打开（见 [右侧面板](panels.md)）。通过 Shell 等工具产生的改动不在追踪范围内，卡片底部会注明「未计入统计」。

## 撤销本轮文件改动

如果对最新一轮的文件修改不满意，点击改动卡片右上角的「↶ 撤销」，核对将要还原或删除的文件列表后点击「撤销文件改动」。

这里的撤销**只还原文件，保留对话记录**，并告诉模型这些文件已还原，方便你直接补充要求让模型重改。如果你想连同对话记录一起回到之前的某条消息，见 [回退和分叉](rewind.md)。
