# 连接服务商

首次提问前需要先配置至少一个模型服务商。

- **桌面端**：点击左栏底部「设置」→「服务商」，也可在输入框的模型菜单底部点击「管理服务商…」。左列分为「已配置」和「可添加」两组。
- **终端**：运行 `nctrn setup` 打开全屏配置页（加 `--cli` 使用逐行向导），或在会话内输入 `/provider`。

## 账号登录与内置预设

在「可添加」中选择预设后，按右侧表单完成配置：

- **ChatGPT / Grok 账号登录**：选择 `ChatGPT` 或 `Grok`，点击「开始登录」打开浏览器完成授权。如果浏览器未自动打开或回调受阻，可在等待卡中点击「复制链接」、「重新打开浏览器」，或点击「粘贴回调地址」/「粘贴授权码」手动提交。登录完成后点击「获取模型」，确认列表后点击「保存」。
- **Grok CLI**：选择 `Grok CLI`，直接读取本机 `~/.grok/auth.json` 中的登录凭据；凭据过期时在终端运行 `grok login` 续期。
- **OpenRouter**：选择 `OpenRouter`，可在「浏览器登录」与「粘贴密钥」之间切换，也可点击「改用环境变量」读取 `OPENROUTER_API_KEY`。
- **DeepSeek / Anthropic / OpenCode Zen / OpenCode Go**：选择对应预设，在输入框粘贴 API Key（Windows 下由 `Windows DPAPI` 加密保存在系统凭据存储中，不写明文配置），或点击「改用环境变量」（默认变量名分别为 `DEEPSEEK_API_KEY`、`ANTHROPIC_API_KEY`、`OPENCODE_API_KEY`）。填好后先点「获取模型」，再点「保存」。

## 接入 OpenAI 或 Anthropic 兼容服务

1. 在「可添加」中选择「其他 OpenAI 兼容服务」或「其他 Anthropic 兼容服务」。
2. 填写服务商名称（作为唯一标识，例如 `demo`）和「服务地址」：
   - OpenAI 兼容端点通常以 `/v1` 结尾；
   - Anthropic 兼容端点留空时默认使用官方 `https://api.anthropic.com/v1`。
3. 如果网关要求每个会话固定携带会话标识请求头，在「会话标识请求头」中填写请求头名（如 `x-opencode-session`），否则留空。
4. 粘贴 API Key，或点击「改用环境变量」（默认 `NOCTURNE_API_KEY`）。
5. 点击「获取模型」拉取上游模型列表，确认后点击「保存」。如果上游不提供模型列表，按提示手动填写模型 ID 后保存。

对于已保存的自定义服务商，在「已配置」中选中后可点击「编辑」修改「显示名称」、「协议」（「OpenAI 兼容」或「Anthropic 兼容」）、「服务地址」、添加「自定义请求头」（点击「＋ 添加请求头」）和「会话标识请求头」；也可以点击「换密钥」或「刷新模型列表」。

## 启停模型与修正模型能力

Nocturne 会自动结合上游 `/models` 返回值与内置 `models.dev` 数据识别模型的上下文窗口、最大输出、推理和看图能力。

在「服务商」详情页下方的「模型」表格中：

- 可以按行切换「启用」开关，或点击「全部启用」/「全部停用」隐藏不需要的模型；
- 点击模型行右侧的「设置」，可针对单个模型覆盖「显示名」、「上下文长度」、「最大输出」、「推理」、「图片输入」、「思考档位」、「协议」（`Chat Completions`、`Messages`、`Responses`、`Gemini`）、「编辑工具」（`edit` 或 `apply_patch`）以及「接口地址」。

## 切换模型与模型角色

- **当前会话切换**：点击输入框右下角的模型按钮切换模型（支持搜索），点击旁边的档位按钮切换思考档位（`off` 和模型支持的 `minimal`、`low`、`medium`、`high`、`xhigh`、`max`）。终端内输入 `/model` 和 `/effort`。
- **全局默认与角色模型**：在「设置」→「模型」页，点击「默认模型与档位」右侧的「选择」设置新会话的默认模型；在「模型角色」分组中，可分别为「子代理模型」、「视觉模型」（当前模型不支持图片输入时负责代看图）和「轻量模型」指定模型。
