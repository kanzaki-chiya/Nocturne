# 上下文和用量

## 查看上下文占用

每个模型都有固定的上下文窗口上限（例如 200k tokens）。

- **桌面端**：输入框底部状态栏右侧实时显示当前上下文占用百分比（如 `24%`）。点击该百分比按钮，会弹出「上下文」面板，展示四部分的 Token 构成：**系统提示词**、**工具定义**、**对话消息**和**预留输出**，并列出占用最高的前 5 项工具。
- **终端 TUI**：底部状态栏显示当前占用百分比与会话费用；输入 `/context` 可打开上下文构成面板。

## 上下文压缩

随着对话变长，早期消息和大型工具输出会逐渐占满上下文窗口。Nocturne 提供自动与手动两套压缩机制：

### 自动压缩

当上下文占用达到触发阈值（默认 **80%**）时，Nocturne 会在发送下一轮请求前自动执行两步清理：

1. 先修剪较早轮次中体积较大的工具原始输出；
2. 若仍超过阈值，则将较早的对话历史总结为结构化摘要，同时完整保留最近几轮对话和当前未完成的任务清单（`todo_write`）。

### 手动压缩

在开始一个全新子任务前，你可以主动压缩上下文：

- **桌面端**：点击右下角上下文百分比，在弹出的「上下文」面板底部填写「保留重点（可选）」后点击「压缩」。
- **终端 TUI**：输入 `/compact`（或 `/compact 保留接口定义和错误日志`）立即压缩。

### 压缩设置

在桌面端「设置 → 通用 → 上下文压缩」或配置文件的 `context.compaction` 字段中，可以开关「自动压缩上下文」、调整「触发阈值」（`50%`–`95%`，默认 `80%`）或填写「摘要保留要求」（`context.compaction.instructions`）。

## 用量统计与费用估算

- **桌面端**：点击左侧边栏底部的「用量统计」打开统计页，可切换「7 天」「30 天」「全部」时间范围，查看「总费用」「总 Token」「缓存命中」「请求数」汇总卡片、每日趋势图，以及按模型、常用工具与常用技能的统计明细。
- **终端 TUI**：输入 `/usage`（支持 `/usage 7`、`/usage 30`、`/usage all`）查看本地 Token 用量与估算费用。
- **自定义模型价格**：内置服务商模型自带参考单价；对于自定义模型，可在「设置 → 服务商」点击模型行的「设置」填写每百万 Token 的输入/输出价格，或在配置文件的 `providers[].models[].pricing` 字段中指定。
