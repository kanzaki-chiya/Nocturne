# 上下文和用量

Nocturne 会实时计算当前会话的上下文窗口占用，在接近上限时自动执行两级压缩，并提供跨会话的 Token 与费用统计。

## 查看上下文占用

- **桌面端**：会话底部状态栏实时显示当前状态（「空闲」、「思考中」、「执行工具」、「压缩中」等）、上下文占用百分比、累计 `tokens`、提示词「缓存」命中率以及最近一步的生成速度（悬停速度可看「输出」、「其中推理」、「TTFT」、「生成用时」、「请求总耗时」）。点击状态栏的百分比（`上下文用量`），会弹出明细面板，列出当前估算 Token 与可用输入预算，以及各部分的构成：
  - 「系统提示」、「工具定义」、「项目说明」（如 `AGENTS.md`）、「技能目录」、「环境」、「任务清单」；
  - 「对话历史」及其四项细分：「用户消息」、「助手回答」、「工具调用与结果」、「压缩摘要」；
  - 「图片」（图片附件按每张固定 1600 tokens 计入估算）；
  - 「其他」。只在上面这些行的 token 加起来小于总量时出现，数字是两者的差。终端里这一行写作 `other`。各项数字不会为了和总量对齐而被改小。
- **手机端**：会话页右上角的圆环显示上下文占用，点击弹出同一张明细面板。
- **终端（TUI 与 CLI）**：输入 `/context` 查看相同的上下文组成报告。

可用输入预算等于模型的「上下文长度」减去「最大输出」预留和安全余量。

## 桌面端切换 Git 分支

会话底部状态栏的 MCP 左侧显示当前分支，点击可搜索并切换；输入不存在的名字时，点击「新建分支 <名字>」可从当前提交创建并切换。当前分支打勾；其他工作树占用的分支禁用，悬停显示工作树路径。游离 HEAD 显示提交号前 8 位，非 Git 仓库或读取失败时隐藏分支项。

同一目录下有会话运行、压缩、回退或共享目录的后台子代理时不能切换；隔离工作树中的后台子代理或已用 `switch_worktree`（「切换工作树」）切到其他工作树的会话不阻止原目录切换。未提交改动由 Git 判断能否带到目标分支，不自动 stash；失败时菜单保留并显示 Git 的错误原文，成功后直接更新分支名。

打开会话、打开菜单、回合结束、会话切换工作树和窗口重新获得焦点时更新分支。在外部终端切换分支后，下一轮会把分支变化和先前读到的文件内容可能过时的说明带给模型。恢复会话也会发现离线期间的切换。手机端与 TUI 没有此入口。

## 切换工作树

可以让主会话使用 `switch_worktree`（「切换工作树」）切到同一 Git 仓库中已经存在的工作树。例如先创建目标工作树，再告诉模型「切换到那个工作树继续修改」。`path` 指定 `git worktree list` 中的工作树根目录，支持绝对或相对路径；工具不会创建工作树，子代理不能调用它。若会话从仓库子目录启动，会保留相同的子目录位置；目标缺少该子目录时切换失败。

切换后，相对文件路径、命令、Git 分支读取、文件面板和新开终端跟随当前目录；侧栏分组、项目配置、信任、项目授权、技能和项目说明仍来自最初的项目目录。子代理隔离副本从当前工作树的 HEAD 创建，改动也并回当前工作树。切换后的会话不能直接修改同仓库其他工作树；读取仍遵循原权限规则，成功时附带目录提示。

回退对话时当前目录随回退点恢复；分叉会话继承分叉点的目录。重新打开会话时继续使用上次目录；若该目录已删除，则回到项目目录并将变化写入会话记录。切换到工作区外的目标可能需要按读取权限确认。

## 自动与手动压缩

当对话变长时，Nocturne 按两级策略回收上下文空间，并保留最近一段对话原文（保留区约占可用输入预算的 20%，在 20k–40k tokens 之间）：

1. **L1 修剪（Prune）**：不调用模型，直接把较早步骤中非固定的工具输出替换为 `[输出已省略]` 占位说明，并截短超过 200 字符的工具调用参数。默认在上下文达到可用预算的 80% 或达到绝对「修剪上限」（`compaction.pruneLimit`，默认 `200000` tokens，设为 `0` 表示不设绝对上限）时触发。
2. **L2 摘要（Summary）**：当修剪后仍高于比例阈值，或上下文达到「摘要阈值」（`compaction.threshold`，默认 `90%`）时，调用模型将早期历史总结为结构化「压缩摘要」（包含目标、已完成工作、任务清单状态、关键文件与下一步），并附上最近读写过的文件列表。如果压缩发生在长回合中途，当前回合的原始提问与插话会自动重新附在摘要之后，防止模型丢失当前目标。

你也可以随时在输入框运行 `/compact` 手动触发一次摘要压缩。

### 调整压缩阈值

在桌面端「设置」→「常规」的「执行」分组中，点击「压缩阈值」右侧的「编辑」，可分别设置：

- 「摘要阈值」（`compaction.threshold`）：支持百分比（如 `85%`）或固定 Token 数（如 `120000`）；
- 「修剪上限」（`compaction.pruneLimit`）：填写正整数 Token 上限（默认 `200000`），填 `0` 关闭绝对上限。

点击「恢复默认」可清除自定义值。

## 跨会话用量统计

点击桌面端「设置」→「用量」，可在顶部切换「7 天」、「30 天」或「全部」时间范围，点击「刷新」重新汇总本地所有会话日志（含主会话、子代理、自动压缩与安全审查的模型调用）：

- **总览卡片**：「累计 tokens」、「预估费用」、「缓存命中率」、「会话 / 轮」（含子代理轮数）和「最长一轮」。
- **每日活跃**：近一年的热力图，可在右上角切换按「Tokens」或「费用」着色，点击格子查看当天的 Token、预估费用和轮数。
- **Token 构成与费用**：拆分展示「普通输入」、「缓存读取」、「缓存写入」和「输出」各自的 Token 数与预估费用。
- **常用工具与常用技能**：展示调用次数最多的前 8 个工具和技能。
- **按模型明细**：支持「按费用」或「按输入」排序，列出每个模型的「轮」、「输入」、「输出」、「缓存命中」、「预估费用」、「Tokens/s」、「TTFT」、「近期速度」、「输入单价」和「输出单价」。点击任意模型行可展开查看「效率」（「缓存命中率」、「缓存节省」）、「延迟」（「平均耗时」、「平均 TTFT」、「Tokens/s」）、详细 Token 拆分与单价，以及随时间变化的吞吐和首字延迟曲线。

费用基于模型声明的单价估算，实际账单以服务商为准。
