# 排队和插话

模型正在思考或执行工具时，不需要先中断当前回合就能继续发消息。运行中提交的消息有两种送达方式：

- **排队（`queue`）**：等当前回合以 `done` 正常结束后，作为**新的回合**自动按序发出，适合交代做完当前任务后再处理的下一件事。
- **插话（`steer`）**：并入**当前回合**，在当前步骤结束的下一个安全点（当前这批工具调用结算完成，或模型文本输出结束准备收尾时）直接交给模型，不打断正在生成的流或运行中的工具，适合中途补充条件或纠正方向。已送达的插话在消息气泡内带有「插话」标记。

## 发送方式

| 客户端 | 排队（`queue`） | 插话（`steer`） |
|---|---|---|
| 桌面端 / 手机端 | 运行中按 `Enter` 或点击发送按钮 | 运行中按 `Alt+Enter`，或先排队再点队列行的「立即发送」 |
| TUI（终端全屏界面） | 运行中按 `Tab` | 运行中按 `Enter` |

行式 CLI（`nctrn --cli`）在回合运行期间只响应中断，不提供排队与插话。

## 管理待发队列

还没有被消费的消息会显示在输入框上方的「待发消息」列表中：

- **桌面端与手机端**：
  - 点击排队消息右侧的「立即发送」（向上箭头图标），可将该条排队消息改为插话，在当前步骤结束时送达；
  - 点击「编辑」（铅笔图标）可就地修改文本，按 `Enter` 或点「保存」生效，按 `Esc` 或点「取消」放弃（修改只替换正文文本，原提交时的图片附件、`@` 文件引用与技能快照保留；若需更换附件，先取消再重发）；
  - 点击「取消」（`×` 图标）撤回该条消息。
- **TUI**：
  - 当待发列表非空且输入框为空时，按 `↑` / `↓` 在列表中移动选中项；
  - 按 `Alt+E` 编辑选中项（`Enter` 保存，`Esc` 取消），按 `Alt+X` 撤回选中项，按 `Alt+T` 在插话与排队之间切换。

后台命令自然结束或异常的结果条目显示「后台任务 · <任务名> · 等待送达」，无名字时显示命令首行，点击「取消」可撤回，不提供编辑或立即发送。已撤回的后台结果在重新打开会话后也不会补送。

如果某条消息在编辑或点击取消的瞬间已经被当前回合取走，界面会提示该条消息已经发出。

## 中断或出错后的暂停与恢复

如果当前回合没有以 `done` 结束（例如你按 `Esc` / `Ctrl+C` 手动中断、请求报错、或达到步数上限），所有尚未发出的待发消息都会转为排队并进入「已暂停」状态，不会自动发出。

此时你可以先编辑或取消不需要的条目，然后点击列表顶部的「继续发送」（TUI 按 `Alt+R`）恢复队列；也可以直接在输入框发送一条新消息，新消息会排入队尾并同时恢复自动发送。
