# 右侧面板

桌面端打开会话后，点击窗口右上角标题栏的「右侧面板」按钮或按 `Ctrl+B` 可展开或收起右侧面板。拖动面板左边缘分隔条（或聚焦分隔条后按 `←` / `→`）可调整面板宽度。

面板顶部支持多标签页：点击 `+`（「新标签页」）或按 `Ctrl+T` 新建标签页，支持拖拽排序、鼠标中键或 `Delete` 关闭。每个会话各自记住打开的标签页。

## 文件（`Ctrl+P`）

按 `Ctrl+P`（或点击「新标签页」里的「文件」卡片）打开「快速打开」搜索框，输入文件名筛选当前工作区的文件，按 `Enter` 在面板中以「只读」标签页打开。点击对话回答中的代码路径（如 `src/index.ts:42`）或改动卡片中的文件也会在面板中打开并定位到对应行。

文件标签页支持代码语法高亮与图片预览（单文件上限 2 MB）：

- 顶部工具栏可点击外部编辑器按钮（「在外部编辑器打开」）或点击刷新图标（「重新读取」）；
- 如果打开的是 `.html` 文件，顶部还会显示在内置浏览器中打开的按钮；
- 超过 2 MB 或二进制文件会提供「在外部编辑器打开」和「在资源管理器中显示」按钮。

## 变更（`Ctrl+Shift+G`）

按 `Ctrl+Shift+G`、点击「新标签页」里的「变更」卡片、点击对话改动卡片上的「查看变更」，或在右上角「会话概览」浮层中点击「变更」，都会打开「变更」标签页。

- **左侧差异区**：按轮次展示本会话内追踪到的文件 Diff，标注「新建」、「已删除」或「已撤销」，右上角可点击「换行」切换自动换行。
- **右侧文件树**：汇总本会话改动的轮数与文件数，可在「筛选文件」输入框按路径过滤；同一文件在多轮被修改时可展开按轮定位；拖动中间分隔条可调整文件树宽度。

面板中的「变更」标签只读展示差异；撤销文件改动请在对话流的改动卡片上点击「↶ 撤销」。

## 终端（`` Ctrl+` ``）

按 `` Ctrl+` `` 或点击「新标签页」里的「终端」卡片，可在右侧面板打开工作目录位于当前工作区的交互式终端（如果已有终端标签则直接切过去）。

- **Shell 选择**：新开终端默认跟随「设置」→「常规」→「执行」中的「Shell」配置；点击终端右上角的「Shell」下拉菜单可单独切换当前标签页的 Shell（支持已安装的 `pwsh.exe`、`powershell.exe`、`bash.exe`、`cmd.exe`）。终端字体与字号自动跟随「设置」→「外观」中的「代码字体」与「字号」。
- **复制与粘贴**：有选区时按 `Ctrl+C`、`Ctrl+Insert` 或 `Ctrl+Shift+C` 复制；无选区时 `Ctrl+C` 发送中断信号；按 `Shift+Insert` 或 `Ctrl+Shift+V` 粘贴。鼠标右键遵循 Windows Terminal 习惯：程序未开启鼠标上报时，有选区即复制，无选区即粘贴。
- **生命周期**：切换会话或收起面板时终端进程在后台保持运行；进程退出后可点击「重新启动」。面板终端完全由你控制，模型看不到也无法操作它。

## 网页与 Agent 浏览器

在「新标签页」顶部的「地址栏」输入网址（`https://...`、`localhost:3000`）或工作区内的 HTML 文件路径并按回车，即可在面板内置浏览器标签中打开网页。工具栏提供「后退」、「前进」、「重新加载」/「停止」、「地址栏」、「在系统浏览器打开」和「开发者工具」按钮。

当在「设置」→「常规」的「执行」分组开启「面板浏览器」开关（首次开启需点击「仍然启用」确认）后，模型通过内置的 `desktop_browser` 工具操作网页时，面板会出现带 `agent` 或「子代理」徽标的受控网页标签：

- 标签显示「agent 控制中」或「agent 正在操作」；当需要手动登录或过验证码时，点击工具栏的「接管」（或直接点击网页区域）即可暂停模型操作并由你接管输入；处理完后点击「交给 agent」恢复模型控制；
- 若网页弹出 `alert`、`confirm`、`prompt` 等脚本对话框，工具栏下方会显示横幅，由你点击「确定」或「取消」放行。

## 子代理与会话概览

当模型通过 `task` 工具启动内置子代理时，点击对话中工具行的「在面板中查看」，即可在右侧面板打开该子代理的「只读」标签页，实时查看子代理的思考、工具调用、耗时和「最终结果」。

点击窗口右上角标题栏的「会话概览」按钮（或在输入框空闲且无弹窗时按 `Esc`）会弹出「会话概览」浮层，集中展示当前项目路径、本会话「变更」总行数、正在运行的「子代理」（后台子代理可直接点击「取消」）以及工作树隔离留下的「保留的副本与分支」（可点击「删除」清理）。
