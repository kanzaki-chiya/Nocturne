# 右侧面板

## 打开与分屏布局

桌面端右侧面板集成了文件浏览、Diff 审查、终端、网页预览和子代理监控：

- 点击窗口右上角的「切换右侧面板」按钮，或按 `Ctrl+B` / `⌘B` 展开或收起右侧面板。
- 点击标签页右上角的「向右分栏」（或拖拽标签到窗格边缘）可将面板拆分为并排网格；拖拽分隔线可调整宽度，点击「最大化面板」可临时全宽查看。

## 文件

- 按 `Ctrl+\` / `⌘\` 打开工作区「文件树」，点击目录展开层级，点击文件在面板标签页中查看带行号和语法高亮的源码。
- 按 `Ctrl+P` / `⌘P` 打开快速打开弹窗，输入文件名搜索并直接打开工作区文件。
- 对话流中模型提到的 `路径:行号` 链接点击后也会直接在右侧面板打开对应文件并跳到目标行。

## 变更

「变更」标签页用于审查代码改动并提交 Git 变更：

- **工作区改动**：可切换查看「未提交」或「相对基准分支」的变更，按「暂存的更改」与「更改」分组展示文件，支持直接暂存、取消暂存、放弃更改，或在底部填写提交说明后点击「提交」。
- **本轮变更详情**：点击对话流中某轮回复下方变更卡片的「查看详情」，可在右侧面板打开该轮的文件 Diff。

## 终端

- 按 `` Ctrl+` `` 打开内置交互式终端，默认以当前会话的工作区目录启动。
- 支持创建多个独立终端标签页，用于手动跑开发服务器、查看日志或执行 Git 操作。

## 网页与 Agent 浏览器

- **网页标签页**：按 `Ctrl+Shift+B` / `⌘⇧B` 打开内置「网页」标签页，输入本地开发服务器地址（如 `http://localhost:3000`）即可边改代码边看页面效果。
- **Agent 浏览器**：当模型调用内置浏览器工具（`desktop_browser`）访问和操作网页时，右侧面板会自动打开「Agent 浏览器」窗格，实时显示模型的浏览画面与操作过程。

## 子代理

当主代理通过 `task` 工具派发子代理时，点击对话流中的子代理卡片，即可在右侧面板打开该子代理的详情标签页：

- 实时查看该子代理独立会话的推理过程、工具调用流和最终输出，或向运行中的后台子代理追加说明。
- 对在独立 Git 工作树（`worktree`）中运行的后台子代理，任务完成后可在该面板预览文件改动，并点击「应用变更」（或「三方合并」）将改动合并回当前分支（详见 [子代理](subagents.md)）。
