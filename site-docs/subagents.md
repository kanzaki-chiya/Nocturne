# 子代理

子代理（Subagent）是在独立子会话中运行的受控 Agent。主会话通过内置的 `task` 工具把独立的查找、调研或跨文件修改任务委派给子代理，子代理只返回最终结构化结果或摘要，避免中间大量的搜索和读文件输出撑满主会话上下文。

## 什么时候用子代理

- **代码检索与只读调研**：使用 `explore` 工具集预设，子代理只能调用 `read`、`grep`、`glob`、`web_fetch` 以及标为只读的 MCP 工具，适合在仓库中定位实现、汇总接口用法。
- **独立模块实现与重构**：使用默认的 `general` 工具集预设，子代理拥有工具集允许的内置工具，不包含仅供主会话使用的 `task` 和 `switch_worktree`（子代理不能再派生子代理，深度固定为 1）。
- **多任务并行**：主会话传入 `background: true` 可启动后台子代理（每个会话最多同时运行 3 个）；含写操作时默认使用独立 Git worktree，只读任务默认不隔离。显式 `isolation: "none"` 的可写后台任务会被拒绝；非 Git 目录或没有提交的仓库无法创建工作树，应使用只读子代理或由主代理直接完成。

`task` 默认不设超时或步数上限；需要限时可显式传入 `timeoutMs`，它优先于档位与 Runtime 的可选超时，不设固定封顶。`maxStepsPerTurn` 仅显式配置才限制子会话单轮步数。后台并发默认上限 3、重复调用保护和 `finish` 催促轮次不变；取消任务仍可立即结束等待。定时任务的独立 60 分钟限制不受影响。

### 子代理的权限边界

子代理运行在非交互子会话中，**无法向你弹出权限确认框或提问框**：

- 权限层判定为 `allow` 的操作正常执行（主会话已授予的「本会话允许」和「本项目允许」授权会自动继承给子代理）。
- 权限层判定为 `ask` 或 `deny` 的操作会被立即拒绝并记录到子代理结果中，交回主会话由你审批或由主会话直接执行。

## 查看子代理与合并改动

工具行收起时，未通过准入的子代理显示「未启动」，展开可看原因。标识显示启动时指定的工具集预设或命名档位，没有时不显示 `default`。

- **在面板中查看详情**：对话流中的子代理工具行与「子代理结果」折叠卡右侧均提供「在面板中查看」按钮；点击后会在右侧面板打开「子代理」标签页，展示该子代理的完整对话、工具调用、文件改动与底部统计（见 [右侧面板](panels.md)）。
- **查看与合入 Worktree 改动**：使用 `isolation: "worktree"` 的后台子代理如果修改了文件，「子代理结果」卡片会列出改动文件与增删行数（点击文件名可在右侧面板打开 Diff），主会话随后可调用 `apply_subagent_changes`（「并回子代理改动」，支持 `clean` 干净合并与 `3way` 三方合并）将独立 worktree 的改动合入主会话当前工作树；切换执行目录见 [切换工作树](context.md#切换工作树)。

## 配置子代理档位（Profiles）

也可以直接在对话里让主模型用指定模型和思考档位开子代理，无需先建档位，说模型名就行。多个服务商都有同名模型时，模型会问你选哪个。

打开桌面端「设置」→「子代理」（或配置 `subagents.profiles`），左列顶部的「内置档位」分组管理主会话可选择的档位：

- **`default` 档位**：始终启用，不能关闭，默认跟随当前会话的模型与思考档位；选中 `default` 时指定的「模型」（或前往「设置」→「模型」设置的「子代理模型」，对应配置项 `modelRoles.task`）会作为未显式指定模型时的默认子代理模型。
- **添加自定义档位**：点击右上角「添加档位」，在右侧的表单中配置：
  - 「名称」（小写字母、数字与连字符）与「描述」（主会话据此决定何时选用该档位）；
  - 「模型」（特定模型或「跟随当前模型」）与可选的「默认超时（秒）」（留空表示不设置，不限制最大值）；
  - 「思考档位」（「跟随会话」、`off` 或具体档位）与「工具集上限」（「全部（general）」或「只读（explore）」，主会话调用时只能收窄工具集、不能放宽）；
  - 打开右上角的开关启用档位，然后点击「保存」。底部可展开「预览模型看到的文字」查看实际注入给 `task` 工具的档位说明；不再需要时可点击「删除档位」。
