# 定时任务

## 创建定时任务

定时任务可以按固定计划自动启动新会话执行指令（如每日代码巡检、汇总更新或定时跑测试）。

### 在桌面端创建

1. 点击左侧边栏底部的「定时任务」打开管理页。
2. 点击右上角的「新建」，填写「名称」、「计划」、「工作区」（选择已打开项目或「自定义目录…」，选择「无（普通对话）」则为无工作区会话）、「权限」、「模型」、「推理强度」、「最长运行」与「指令」并点击「保存」。
3. 在任务列表中可随时点击「立即运行」、切换启用/暂停开关、点击「编辑」或「删除」；展开任务的「运行历史」可查看每次执行的结果，并点击「打开会话」跳转到对应会话。

### 在对话中创建

你也可以直接用自然语言让模型调用内置 `schedule` 工具创建、修改、暂停或删除定时任务（创建、修改、暂停和删除操作均需你确认后生效）。

## 支持的计划类型

| 界面选项 | 配置写法 | 规则说明 |
| --- | --- | --- |
| 按间隔 | `{ "type": "interval", "minutes": 60 }` | 每隔 N 分钟运行一次，最小间隔为 30 分钟 |
| 每小时 | `{ "type": "hourly" }` | 每小时整点运行 |
| 每天 | `{ "type": "daily", "time": "09:00" }` | 每天在指定本地时间（`HH:MM`）运行 |
| 工作日 | `{ "type": "weekdays", "time": "09:00" }` | 周一至周五在指定本地时间运行 |
| 每周 | `{ "type": "weekly", "day": "mon", "time": "09:00" }` | 每周指定星期几（`mon`–`sun`）运行 |
| Cron 表达式 | `{ "type": "cron", "expr": "0 9,18 * * *" }` | 五段式 Cron（本地时区），相邻两次触发间隔不少于 30 分钟 |
| 仅手动运行 | `{ "type": "manual" }` | 不自动触发，仅在界面点击「立即运行」时执行 |

## 运行方式与补跑规则

- **运行条件**：定时任务保存在 `~/.nocturne/schedules.json`，仅在 **Nocturne 桌面端处于打开状态**时由内置调度器触发。
- **独立会话**：每次触发都会创建一个全新的独立会话，看不到你之前的对话历史。因此指令里必须写清完整的目标目录、判断标准、输出格式和保存位置。单次运行默认最长 30 分钟（可在 `1`–`1440` 分钟之间设置）。
- **错过补跑**：如果电脑睡眠或桌面端关闭期间错过了触发时间（7 天内），下次打开桌面端时**只会补跑最近一次**错过的执行，更早的错过记录会记为「已跳过（错过）」。

## 无人值守的权限

定时任务触发的运行处于**无人值守（非交互）状态**：任何需要弹窗确认的操作都会被权限层立即拒绝，不会挂起等待。

- 只读巡检或汇总任务：将任务的权限设为「只读」（`read-only`）。
- 需要修改工作区文件的任务：设为「自动编辑」（`auto-edit`）。
- 需要执行构建或测试命令的任务：设为「智能」（`smart`）或「完全访问」（`guarded`），或者提前为该项目配置好持久授权（见 [权限模式](permissions.md)）。

当你事后点击「打开会话」进入某次定时任务生成的会话并发送新消息后，该会话即转为正常交互模式。
