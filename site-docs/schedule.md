# 定时任务

定时任务让你按设定的时间计划在后台自动创建新会话并执行一段提示词，适合每日代码巡检、测试汇总、依赖检查等周期性工作。

## 创建与管理定时任务

在桌面端左栏顶部点击「定时任务」进入管理页，或由模型在会话中调用内置 `schedule` 工具（需你审批确认）。

点击右上角「新建任务」，在表单中填写：

- **「名称」与「指令」**：每次触发都会在**全新的会话**中运行，看不到当前对话历史，因此需要在「指令」中写清完整背景、目标目录、判断标准与产出位置。
- **「工作区」与「模型」**：工作区可选「普通对话」或已添加的项目；模型可选「默认」或指定 `provider/model`。
- **「计划」**：支持以下计划类型：
  - 「按间隔」（`interval`）：每隔指定分钟运行一次（不少于 `30` 分钟）；
  - 「每小时」（`hourly`）：每个整点运行；
  - 「每天」（`daily`）：每天在指定本地时间（`HH:MM`）运行；
  - 「工作日」（`weekdays`）：周一至周五在指定本地时间运行；
  - 「每周」（`weekly`）：每周指定星期几（周一至周日）的指定时间运行；
  - 「手动」（`manual`）：不自动触发，只在点击「立即运行」时运行；
  - `Cron`（`cron`）：五段本地时区 Cron 表达式（相邻两次触发间隔不少于 30 分钟）。
- **「权限」、「思考档位」与「单次时长上限」**：设置无人值守运行时的权限预设、思考档位，以及单次运行超时上限（默认 `60` 分钟，可选 `30`、`60`、`120`、`240` 分钟）。

点击「保存」生效。选中已有任务后，可在右上角切换「启用」开关、点击「立即运行」立即触发一次，或在「设置」与「历史」标签页之间切换；点击底部「删除任务」→「确认删除」可删除任务及其运行历史。

## 运行方式与调度规则

- **仅在桌面端打开时运行**：调度器内置于 Nocturne 桌面端后台（配置保存在 `~/.nocturne/schedules.json`，每个任务的运行历史保存在 `~/.nocturne/schedules/history` 目录下）。桌面端关闭期间不会触发；重新打开桌面端后，错过的计划最多只补跑最近一次。
- **单实例互斥与防重入**：同一台电脑打开多个桌面端窗口时，只有一个实例负责调度；同一任务如果上一次运行仍未结束，下一次触发会自动记为「跳过」，不会并发重入。
- **查看运行历史与会话**：在任务详情页切换到「历史」标签页，表格列出每次运行的「开始时间」、「结果」（「完成」、「出错」、「超时」、「中断」、「已跳过」）、「用时」、「被拒」次数与「会话」入口，点击「打开会话」可跳转到该次运行生成的完整会话记录。左栏会话列表中由定时任务产生的会话带有「定时」标记。

## 无人值守下的权限

定时任务在后台无人值守运行，**不会弹出权限确认框或提问框**：

- 任何在权限层判定为 `ask` 的工具调用都会被直接拒绝（计入运行历史的「被拒」次数），`ask_user` 工具不可用。
- **只读汇总类任务**：将任务的「权限」设为 `read-only`（只读工具自动放行，写操作拒绝）。
- **需要修改工作区文件的任务**：将「权限」设为 `auto-edit`（工作区内文件读写自动放行）。
- **需要执行固定命令或访问特定域名的任务**：提前在「设置」→「授权」中为该工作区授予项目级授权，或在 `.nocturne/config.json` 的 `permissions.rules` 中配置显式 `allow` 规则（需先信任项目，见 [权限模式](permissions.md)）。
