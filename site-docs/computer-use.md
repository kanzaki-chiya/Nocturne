# 电脑操控

Windows 桌面端内置了电脑操控能力（基于随附的 `cua-driver`），可以让模型观察桌面窗口，并在你授权的软件里执行点击、输入、快捷键和窗口操作。功能默认关闭；TUI 和命令行自行启动时不包含这一来源。

## 开启与关闭

1. 打开「设置」→「电脑操控」。
2. 打开「电脑操控」开关，在同行确认提示中点击「仍然启用」。
3. 驱动当场启动，状态显示「运行中」与随附的 `cua-driver` 版本；不需要重启应用。

关闭开关后，驱动进程立即退出；正在运行的回合不受影响，从下一个回合起模型不再看到电脑操控工具。

同一卡片还提供：

- **「驱动」**：查看当前状态（「未启动」、「启动中」、「运行中」或「启动失败」），点击「重启」可重新启动驱动进程。若全局停止快捷键被其他软件占用，状态会显示「运行中（停止快捷键未绑定）」。
- **「显示光标」**：默认开启，在屏幕上显示模型的操作轨迹；关闭后轨迹立即隐藏。

## 软件权限

电脑操控使用独立的软件权限类别（`app`），不受会话权限预设（如「自动编辑」、「全自动」）或智能审查影响。项目级 `.nocturne/config.json` 即使已信任，也不能放宽软件权限。

在「设置」→「电脑操控」的「权限」分组可以预先配置规则：

- **「其他软件」**：未单独列出的软件默认「询问」，也可改为「允许」或「拒绝」。
- **单独软件规则**：点击「+ 添加软件」会列出当前有可见窗口的软件（已在列表中的软件不可重复选择），也可点击底部的「浏览…」选择 `.exe` 可执行文件。每个软件可单独设为「允许」、「询问」或「拒绝」，点击右侧 `×` 移除规则。

规则保存在用户级 `~/.nocturne/config.json` 的 `permissions.rules` 中（`kind: "app"`）。普通程序按小写可执行文件名匹配（如 `excel.exe`），商店/打包应用按包族名匹配。

## 会话内确认与停止

当模型首次操作某个需要询问的软件时，对话底部会弹出「需要确认 · 操作软件」卡片，展示软件图标、名称、标识和当前窗口标题，并提供三个选项：

- **「本会话允许」**（快捷键 `1`）：当前会话后续操作该软件不再询问，换用其他软件仍会询问；
- **「始终允许 <软件名>」**（快捷键 `2`）：写入用户级规则，新会话也继续生效，并出现在「设置」→「电脑操控」列表中；
- **「拒绝」**（快捷键 `3` 或 `Esc`）：拒绝本次操作。

模型切到前台向目标窗口发送点击或按键期间，窗口底部状态栏会显示正在操控的软件名称和「停止」按钮。你可以随时点击「停止」或按全局快捷键 `Ctrl+Alt+Esc` 中断当前回合。

## 剪贴板保护

模型通过电脑操控写入剪贴板前，会先备份当前剪贴板中的纯文本；当前回合结束或中断时，如果剪贴板内容仍是模型最后写入的值，会自动恢复为你原本的文本；如果你在中途自行复制了新内容，则保留你的新内容不覆盖。
