# 常见问题

## Windows 安装时触发 SmartScreen 拦截提示？

安装包尚未做代码签名，首次运行触发 Windows SmartScreen 提示属于正常现象。点击弹窗上的「更多信息」→「仍要运行」即可完成安装。

## 为什么写在 `config.json` 里的 API Key 会报错？

为了防止密钥意外随配置文件提交或泄露，Nocturne 拒绝在 `config.json` 或 `providers.json` 中直接写入明文密钥（会触发 `config_credential_rejected` 错误）。请在桌面端「设置」→「服务商」或运行 `nctrn setup` 粘贴密钥（加密保存在系统凭据库），或者使用 `apiKeyEnv` 引用环境变量。

## 为什么项目 `.nocturne/config.json` 里的 MCP 服务器或 `allow` 规则没有生效？

来自代码仓库的 `.nocturne/config.json` 默认处于未信任状态：未信任时只采纳其中收紧权限的 `ask` 和 `deny` 规则，所有 `allow` 规则、模型切换、MCP 服务器和 Hooks 都会被忽略。在桌面端打开「设置」→「授权」选中该项目点击「信任此项目」，或在项目目录下运行 `nctrn trust` 后即可生效。

## 恢复会话时提示会话被锁定（`session_locked`）怎么办？

同一个会话同一时间只允许被一个进程打开以保护日志完整性。如果该会话仍在桌面端或另一个终端窗口中打开，请先在原窗口关闭或切走；如果之前的进程异常退出留下了残留锁文件，可在终端恢复时加上 `--force-unlock` 参数清理残留锁。

## 为什么模型不支持发图，或者粘贴图片后提示无法发送？

所选模型需要声明支持图片输入（`imageInput`）。你有两种处理方式：

1. 如果该模型实际上支持看图，可在桌面端「设置」→「服务商」点击该模型右侧的「设置」（或运行 `nctrn` 后用 `/provider`），开启「图片输入」开关。
2. 如果当前模型确实是纯文本模型，可在「设置」→「模型」的「模型角色」下配置一个支持看图的「视觉模型」（`modelRoles.vision`），之后发送的图片会自动由视觉模型转为文字描述再交给当前模型。

## 为什么「撤销」或「编辑并重发」没有还原我通过终端命令修改的文件？

检查点只追踪通过内置文件编辑工具（`write`、`edit`、`apply_patch`）修改的文件。模型通过 `shell` 工具运行脚本、MCP 工具或外部程序产生的文件变动不会计入检查点（改动卡片上会提示「未计入统计」），这部分修改需要通过 `git checkout` 等 Git 命令手动还原。

## 遇到问题如何查看或导出诊断日志？

- **桌面端**：打开「设置」→「后台日志」，在右上角「后台」下拉框选择「后台」、「外壳」或「按键诊断」，点击「刷新」查看内存中的最近输出，或点击「复制全部」复制日志文本。后台退出后可从横幅点「查看日志」读取退出时的 stderr 快照；保留与恢复规则见[桌面端文档](https://github.com/kanzaki-chiya/Nocturne/blob/main/docs/apps/desktop.md#2-命令与消息格式)。
- **终端**：启动 `nctrn` 时加上 `--debug`（或设置环境变量 `NOCTURNE_DEBUG=1`），诊断事件会写入 `~/.nocturne/logs` 目录下的 `.jsonl` 文件；将 `--debug-file` 设为 `-` 可直接输出到 `stderr`。
